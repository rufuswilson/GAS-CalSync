# GAS-CalSync v1.2

This release streamlines the Apps Script command surface, removes the manual migration gate, and makes trigger and cleanup behaviour safer for shared projects.

## Changes since v1.1

- Migrates legacy `fromGAS` events automatically during a normal sync. Unchanged events receive the v2 metadata marker, changed events update normally, and obsolete events follow the configured cleanup policy and deletion limit; `PreviewMigration()` and `ApplyMigration()` are no longer required.
- Keeps the primary user-facing commands in `Code.gs` while moving runtime state and implementation details into `Helpers.gs`.
- Makes `AutoUpdate()` the non-preview trigger entry point and keeps update previews in `PreviewUpdate()`.
- Creates or migrates the daily `AutoUpdate` trigger only when the active user is also the effective script owner, avoiding triggers installed under another editor's authority.
- Expands `clearGASEvents()` so it can safely preview or remove owned events from one configured target or all configured targets.
- Updates migration and cleanup documentation, contributor and funding details, and automated coverage for the new behaviour.
