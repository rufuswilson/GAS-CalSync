# GAS-CalSync v1.1

This maintenance release keeps the Apps Script editor's public command surface focused while preserving the existing migration and cleanup behaviour.

## Changes since v1.0

- Replaces the parameterised `clearGASEvents` entry point with a safe, no-argument command that previews cleanup for the configured `Work` target by default.
- Moves the reusable cleanup implementation and internal migration helpers from `Code.gs` to `Helpers.gs`, keeping them available to the sync runtime without presenting them as primary user commands.
- Updates the integration coverage for the public cleanup command and its explicit internal delete path.

## Verification

- All 96 automated tests pass.

See the [README](https://github.com/rufuswilson/GAS-CalSync#readme) for installation and configuration instructions.
