# GAS-CalSync v1.0

The first release of GAS-CalSync combines changes made to derekantrican/GAS-ICS-Sync after its [v5.8 tag](https://github.com/derekantrican/GAS-ICS-Sync/releases/tag/5.8) with this fork's calendar and task sync improvements. Install from this release's source archive or follow the [manual setup instructions](https://github.com/rufuswilson/GAS-CalSync#install-or-update-manually).

## Changes since derekantrican v5.8

- Incorporates the later upstream ICS parser update and compatibility fixes, custom event filters, retries for intermittent feed errors, timezone fixes, and explicit Apps Script permission scopes.
- Adds Google Calendar sources alongside ICS feeds. Source mappings can use objects with per-source settings, colours, and exact target calendar IDs; legacy array mappings still work.
- Adds optional ICS `VTODO` and Google Tasks syncing. Copied tasks are identified through a marker in their notes, and cleanup removes only marked copies.
- Adds attendee, all-day, and date filters for ICS and Google sources. Date-filtered recurring series become individual occurrences with stable identities, including moved and cancelled instances.
- Makes sync safer: a failed or unexpectedly empty source, incomplete target pagination, or event write failure cannot silently clear its target. A script lock prevents overlapping runs. Target calendars must be unambiguous and writable; creating a missing target requires `createTargetCalendarIfMissing: true`.
- Limits cleanup to 100 deletion attempts per run by default and resumes on later runs. Optional `pastEventWindowDays` limits historical event processing. Source-specific identities prevent feeds with the same UID from overwriting one another.
- Improves ICS handling for UTF-8 text, VFREEBUSY-only feeds, HTML descriptions, absolute alarms, Outlook moved instances and Safe Links, Webex timezone aliases, and optional Microsoft tentative-to-free mapping. Adds title prefixes, reminder fallback, and clearer email summaries.
- Adds a release-aware updater with pinned downloads, preview mode, optional email notices, and GitHub token support. It keeps private `Config.gs` and `Filters.gs` when updating.
- Adds a migration guard for existing `fromGAS` events without the v2 identity marker. `PreviewMigration()` lists proposed changes without writing; `ApplyMigration()` checks the reviewed plan again before applying it. New targets sync normally.
- Adds automated syntax, style, and regression checks. The local suite passes 96 tests.

## Before upgrading

- Back up your private `Config.gs` and `Filters.gs`. Review the [configuration guide](https://github.com/rufuswilson/GAS-CalSync#source-options-in-this-fork), especially the default `skipIfEmptyFeed: true`, `maxCleanupDeletesPerRun: 100`, and explicit target creation setting.
- If you already have events copied by an older version, run `PreviewMigration()` and review its actions, then run `ApplyMigration()` before resuming scheduled sync. If the plan changes, preview it again. A large migration may take more than one sync run.
- Review the manifest's Calendar, Tasks, Apps Script API, and email scopes and reauthorize the script when prompted. Task sync is off by default; set `addTasks = true` only if needed.
- Google Tasks stores a due date without its time, so timed task due times cannot be preserved through the Tasks API.

See the [README](https://github.com/rufuswilson/GAS-CalSync#readme) for installation, update, and migration details and [IMPROVEMENTS.md](https://github.com/rufuswilson/GAS-CalSync/blob/stable/IMPROVEMENTS.md) for implemented fixes and remaining work.
